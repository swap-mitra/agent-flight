Regression tests for AI agents.

Record every model and tool call of an agent run. Replay it against your changed agent in CI, and get one verdict: same, changed or failed.

$ pip install ai-flight-recorder Quick start

A one-line prompt change can change everything.

An agent is a loop of model calls and tool calls. Change the prompt, the model or the code, and it can take another path: other tools, other arguments, a refund that should not happen. Flight Recorder makes that path something you can test.

01Record

Wrap your model client and tools. Every call is written to a readable JSONL cassette, with tokens, cost and latency.

02Replay

Run your changed agent against the recording. Tool results come from the cassette, so nothing real is touched.

03Judge

Each case gets a verdict and a diff. The report lands on your pull request.

Three lines to a replayed test.

The pytest plugin loads when the package is installed. Record once, commit the cassette, and CI replays it on every push.

import flight_recorder as fr

client = fr.wrap(OpenAI())            # or Anthropic, or a LangChain model

@fr.tool(effect="irreversible")
def issue_refund(order_id: str, amount: float) -> str: ...

@pytest.mark.fr(cassette="triage/refund_over_limit")
def test_refund_over_limit(fr_run):
    fr_run.output = triage_agent(TICKET)

$ pytest --fr-mode=record    # once, live
$ pytest                     # replayed in CI
failed

A call with no recorded match, an exception, a status change or a different final output.

changed

Tools added, removed or called differently, with the same final output. Accept it with one command.

same

Nothing differs.

Built to stay out of your way.

Invisible interception

Your agent gets exactly what the real call returned or raised. Under 2 ms per call, checked in CI.

Two replay modes

Serve tool results and keep models live to test prompts, or serve model responses too for free, offline, deterministic runs.

Safe by default

Secrets redacted before anything is written. Replay refuses to call an irreversible tool for real.

Cost you can trust

Every call priced from a shipped table, cache and tool fees included. Unknown models record null, never a guess.

Works with your stack

OpenAI, Anthropic, LangChain and LangGraph, or any Python function as a tool.

Your data stays yours

Plain files in your repo. Optional OpenTelemetry export to the backend you already run. No telemetry.
